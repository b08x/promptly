# Ideational: What is being represented?

## Ideational Metafunction (Field)

This is about the *content* - the subject matter, the participants,
the processes, and the circumstances.

**In `promptly.yml`:** `sfl_ideational:`

* **`topic:`**: The main subject.
* **`domain:`**: The specific area (e.g., E-commerce, Healthcare).
* **`entities:`**: Key nouns, concepts, or actors.
* **`processes:`**: Key verbs or actions to consider/perform.
* **`background_context:`**: Essential background info.
* **`positive_constraints:`**: What *must* be included or done.
* **`data_sources:`**: Where information comes from.
* **`output_goal:`**: What the prompt aims to achieve.
